# Loja Online - Projeto Bootstrap

Página inicial de uma loja online de jogos desenvolvida como atividade prática. O projeto é responsivo (adaptado para computador e dispositivos móveis) e construído com HTML5, CSS3, JavaScript e Bootstrap 5.

## Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript
* Bootstrap 5 (via CDN)

## Funcionalidades
* Faixa de aviso no topo
* Barra de navegação com menu hambúrguer, dropdown e carrinho
* Carrossel de destaques
* Grid de categorias e produtos responsivo
* Modal de aviso ao adicionar produto ao carrinho
* Seção de newsletter e rodapé completo
